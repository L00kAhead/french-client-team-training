# Training 

Use this repository data, it somewhat gives the glimpse of the organization 
data. 

## Instruction 

- Clone this repository
- Login into company portal, to get access to the data (5TB).
- Calculation 
  - Length modeled via the von Bertalanffy Growth Function (VBGF)
  - Weight modeled via allometric power scaling.
  - Nutritional wellbeing evaluated using Fulton's Condition Factor (K).
